# Exploratory Data Analysis

## Описание проекта

Проект посвящён первичному анализу датасета с использованием Python и библиотек анализа данных.

## Цели

- Загрузить и изучить датасет.
- Определить размеры таблицы и типы данных.
- Проверить наличие пропущенных значений.
- Рассчитать базовые статистики.
- Построить графики распределения признаков.
- Сформулировать три содержательных наблюдения.

## Структура проекта

- `data/` — исходные данные.
- `notebooks/01_initial_analysis.ipynb` — notebook с анализом.
- `README.md` — описание проекта.

## Окружение

Google Colab выбран, поскольку предоставляет готовую среду Python с возможностью устанавливать библиотеки и выполнять Jupyter Notebook в браузере без локальной настройки `venv` или Conda.

## Используемые библиотеки

- pandas
- matplotlib
- seaborn

## Запуск

Открой notebook в Google Colab, загрузи исходный CSV-файл и последовательно выполни все ячейки.

## Результаты

Результаты включают описание структуры данных, анализ пропусков, базовые статистики, визуализации и три наблюдения о закономерностях в датасете.
